# Azani clothing illustrations

Enamel is the selected storefront icon family. Optimized assets ship from `public/images/icons/enamel/`; the source atlas and extraction script are in `enamel/` here.

The alternative **Cut, Fold, Play** family is preserved in `paper/`, including eleven ready-to-use WebPs in `paper/icons/`, the transparent source atlas, and a reproducible extraction script. It is not imported or served by the storefront.

Both families include shop, dress, shirt, age, new arrivals, sale, trousers, outfit, jacket, sleepwear, and socks. Navigation and category text provide accessible names; the illustrations themselves are decorative.
